# IDEA-001 影响评估:猫猫烧烤店(作物再加工与售卖)

**想法 ID:** IDEA-001 | **评估触发:** DEC-019(triage)→ 本评估(evaluating)
**评估日期:** 2026-08-19 | **组织:** 🎬 director;五部门事实由现有源码与文档证据支撑
**状态结论:** **建议「有条件采纳」** —— 轻量加工站方案可作为下一轮中期增量;前置条件为经济模拟(B-2)验证利润曲线。

---

## 1. 想法还原

玩家收获作物后,可前往「猫猫烧烤店」再加工并售卖成品;种植→出售 扩展为 种植→加工→售卖。加工规则、配方、店铺身份与呈现方式原描述为「待评估」。

## 2. 跨部门事实(每项均基于现有代码/文档证据)

### 🌱 design — 玩家结果与核心循环

| 项 | 事实 |
|---|---|
| 循环影响 | 现有循环:种植→收获→(直接出售 或 投入出售箱)→日结。加工引入第三去向,增加「何时卖原料 vs 何时加工卖成品」的决策;与 PRD 6.8.1「不允许单一作物长期领先超 25%」直接相关 |
| 交互落点 | 现有 `CraftingService.craft`(数据驱动配方、失败不扣料、原子性)可承载加工;UI 需新增「加工站」面板或复用制作面板 |
| 可用性 | 加工站放置/交互可复用 `PlacementService`(预览/冲突/失败不扣料);键鼠/手柄路径须满足 FR-010 既有验收 |
| 范围形态 | 三种形态:① 轻量——农场/集市加数据驱动「烧烤架」放置物 + 新配方(复用现有地图);② 中型——集市新增「烧烤店」地标(`MapLandmarkDefinition` 支持)+ 店主 NPC;③ 大型——新地图 + 日程 + 支线(超出 9.2 边界,不推荐) |

### 🎭 content — 原创性与内容预算

| 项 | 事实 |
|---|---|
| 原创性 | 「烧烤/再加工」概念通用;店名、店主角色、对白、视觉必须原创(PRD 2.2/7.1);「猫猫」命名需 Content Director 审核,避免与任何现有角色命名体系冲突(现有角色名:水工学徒/种源管理员/溪岸巡护员、阿禾嫂/栓子/青砚/絮宁) |
| 内容预算 | PRD 6.9 上限 3 职能 + 4 邻居;店主若为新 NPC 须 PO 批准扩展预算;轻量方案(无新 NPC,仅新配方+放置物)不触碰预算 |
| 配方预算 | 现有 5 配方(6.6);加工配方每作物 1 条,3 种可播种作物(雾萝卜/溪叶菜/琥珀豆)+ 2 种数据作物(铃花莓/蜜穗瓜)至多 5 条,数据化即可,不触碰 ContentValidator 校验边界(新增 recipe 类型需扩 schema 与校验) |

### 🛡️ quality — 验收、回归、风险

| 项 | 事实 |
|---|---|

### 🎬 director — 节奏、优先级、取舍

| 优先级 | 建议排在 B-2 经济模拟与第一拍表现升级之后;不阻塞 C 档与 A 档 |
| 轻量起点 | 若采纳,推荐形态①(数据驱动加工站,零新 NPC、零新地图),价值验证后再考虑扩展 |

## 3. 评估结论

**建议:有条件采纳(形态①轻量加工站)。**

- 采纳条件:① B-2 经济模拟先行,加工利润曲线满足 PRD 6.8.1 且不破坏 174/894 教学节奏;② 内容预算维持 3+4(不新增 NPC),或以 DEC 形式批准扩展;③ 原创性审核通过(店名/配方名/文案)。
- 若经济模拟显示加工路径与直售无差异化价值,或平衡成本过高 → 建议 `deferred`(保留想法,延后)。
- 不推荐形态③(新地图+支线),超出 PRD 9.2 边界与单人开发预算。
