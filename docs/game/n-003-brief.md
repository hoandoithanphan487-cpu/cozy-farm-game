## 2. 实现边界

### In scope

1. **风格规范**：调色板锁定 PRD 7.2 词汇（苔绿/雾蓝/湿土褐/木蜜/铜橙）；尺寸规范 角色 32×48、地块 24×24；角色描述卡（3 职能角色：水工学徒/种源管理员/溪岸巡护员，含 N-001 已定主题色）；Prompt 模板存档。
2. **试点资产**：3 职能角色 idle 贴图；5 作物成熟态贴图；农场地块贴图（草地/可耕地/水边，≤8 种）。**生成方式二选一并声明**：a) PO 经 ChatGPT 图像生成（推荐，按 Prompt 模板产出，`Assets/` 落盘）；b) 实现方选定工具/程序化像素绘制。生成记录（提示词/参数/迭代）存档供审核。
3. **原创性审核**：逐件资产审核记录（`assets/originality-review.md`）：不复制/近似受保护角色、图标、构图；风格词汇符合 PRD 7.1（湿润石材/层叠木构/雾气植物/青铜水工件，无全局纯黑粗边）。
4. **位图管线**：SKTexture 加载（`Assets/` 目录）+ `filteringMode = .nearest` + 整数缩放（PRD 7.1 16:9 内部分辨率）+ 缓存；TextureAtlas 合并（可选，性能更好）。
5. **渲染接入**：`FarmScene.swift` 表现段——角色节点换用像素贴图（NPC ID 关联不变，N-001 视觉定义退为兜底）；作物/地块换用贴图；程序化动效（行走摆幅/收获/对话）保留。
6. **测试**：管线测试——NFR-007 实测（nearest 生效：缩放后像素锐利、无线性插值模糊）、资产完整性（引用贴图存在、尺寸合法）、接入不回归。
7. **证据**：渲染对比截图（程序化 vs 像素，同场景同角色）+ 运行时截图 + 放大验证图。

- ❌ 不改 `ContentID.swift`/`ContentValidator.swift` 稳定 ID 与校验；不改经济/存档 schema/领域逻辑；不改 N-001 已验收音频与设置联动。
- ❌ 不引入任何受保护表达（角色/图标/构图/配色近似即拒）；不复制现有游戏像素资产。
- ❌ 不改 PRD/TDD/台账；不自我 `APPROVED`；不 `git commit`。
- ❌ 不重复 clean test（DEC-015；引用 228/0/0 基线 + N-001 8 测试 + 运行时烟雾）。
- ❌ 全量扩量（4 邻居、集市地图、物品图标、动画帧）不在本任务范围——试点验收后另立任务。
