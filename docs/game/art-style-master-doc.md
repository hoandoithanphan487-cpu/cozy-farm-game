# 《溪谷新芽》美术风格 Master Doc

> 版本：1.0 · 状态：建筑与场景生成的唯一视觉母规范 · Product Owner：用户
>
> 本文件、[建筑美术风格生成 Skill](../../skills/building-art-style-generation/SKILL.md) 与[建筑规范模板](building-art-style-spec-template.md)构成建筑美术 prompt 的唯一允许来源。三者之外的参考资料只能帮助理解制作流程，不得向 prompt 注入新的风格、颜色、造型或构图规则。

## 1. 视觉目标与原创边界

### 1.1 一句话视觉语言

温暖的中世纪溪谷工艺：低分辨率像素以清晰的块面、柔和的暖光、湿润的木石和克制的青铜细节，描绘一个由水渠、梯田、木构与社区共同维护的宁静生活世界。

### 1.2 玩家应当感受到

- **温暖**：木蜜色、麦穗色、铜橙色是光与生活的来源；暗部偏综合色，不用生硬的纯黑。
- **清晰**：远看先读轮廓，中看读功能，近看读材质；可交互、可建造、可损坏和可升级的部分都有明确反馈。
- **低分辨率**：像素是设计语言，不是最后一步的缩小滤镜；每个像素都服务于轮廓、材质或状态。
- **明确反馈**：建筑状态、入口、屋顶层级、可通行边界、升级变化和受损部件，必须靠形状、明度、动画或标记共同表达。
- **中世纪典雅**：采用拱、梁、瓦、石基、木窗、铜件、织物旗帜等历史感构件的抽象组合；不复刻现实建筑、影视场景或任何既有游戏的具体建筑。

### 1.3 参考与禁止模仿

可以参考成熟农场生活模拟类型带来的体验：亲切的低分辨率像素、暖色乡村环境、功能一眼可辨的建筑、角色轮廓鲜明、交互反馈直接。不得参考或复制任何特定作品的精确像素尺寸、提取调色板、建筑立面、屋顶/门窗组合、角色发型服装、UI 排版、地图构图、动画帧、图标或可识别的画师风格。特别是不得以《星露谷物语》的具体像素、颜色值、建筑或角色设计作为生成指令；本文件中的规则是独立重建的原创系统。

**原创性红线：** 禁止描摹、临摹、图生图改色、拼接现成 sprite、复用角色/建筑/地图轮廓，或生成“看起来像某具体游戏”的变体。若 silhouette、配色关系或装饰组合出现可识别近似，退回重设计。

## 2. 像素规格与镜头

| 项目 | 锁定规则 |
|---|---|
| 运行视角 | 俯视与轻微三分之四结合；建筑正面/侧面必须同时露出可读的底座、入口和屋顶层级 |
| 目标内部画布 | 16:9 逻辑分辨率；所有缩放为整数倍，保持像素边缘锐利 |
| 建筑基准网格 | 24×24 px tile；建筑 footprint、门、路径、地基优先对齐 24 px 网格 |
| 建筑生成母稿 | 96×96、144×144 或 192×192 px 的整数倍母稿；最终运行尺寸必须可无损落到 24 px 网格 |
| 角色关系 | 角色基准 32×48 px；建筑门、窗、台阶要以该尺度检查可进入性和比例 |
| 线条 | 1 px 主轮廓；重要遮挡可用 2 px 局部加厚；禁止全局黑色粗描边 |
| 缩放/导入 | 最近邻过滤、整数缩放、无抗锯齿、无自动压缩；透明边界干净 |
| 细节密度 | 轮廓优先，功能细节次之，装饰最后；小型建筑避免超过 3 个高对比焦点 |

## 3. 锁定调色板

以下是本项目独立的起始色票，不是任何外部作品的取色结果。生成 prompt 只能使用色票名称及其十六进制值；新颜色须先写入本表并经内容负责人批准。

| 色票名 | HEX | 主要用途 | 明度角色 |
|---|---|---|---|
| 深溪墨 | `#263638` | 最深结构缝、远处遮挡、文字阴影 | 低 |
| 湿石褐 | `#55484A` | 石基、泥土暗面、木石接缝 | 低中 |
| 栗木影 | `#765247` | 木构暗面、屋檐下、角色发色 | 中低 |
| 苔叶绿 | `#788653` | 草、叶、苔、生态标记 | 中 |
| 雾蓝 | `#7897A0` | 水面、阴天、冷反光、织物 | 中 |
| 河岸青 | `#4F7070` | 水渠边、铜件冷反光、状态辅助色 | 中低 |
| 麦秆金 | `#B58A52` | 稻草、木蜜高光、可收获提示 | 中高 |
| 木蜜 | `#C58A59` | 木材主面、暖光、家具 | 中高 |
| 铜橙 | `#C66E3D` | 青铜水工件、重点交互、升级强调 | 高 |
| 乳白纸 | `#F0D9AD` | 纸张、窗光、UI 浅底、可读高光 | 高 |

### 调色与明度规则

1. 单个建筑常规使用 5–8 个色票：深溪墨/湿石褐作为暗部，木蜜/麦秆金作为暖面，雾蓝/河岸青作为冷平衡，铜橙只做焦点。
2. 暖冷关系优先于纯粹明暗：夜间不把所有颜色压成黑蓝；雨天保留木蜜色，只降低饱和度并增加雾蓝反光。
3. 可交互对象和入口至少比相邻背景高一个明度层级；危险/阻挡状态不得只靠红色，必须叠加形状、纹理或动画。
4. 禁用纯黑大面积填充、荧光色、金属渐变、照片纹理、软阴影、半透明模糊和连续抗锯齿边缘。

## 4. 材质语言

- **木**：大块平面 + 2–3 条沿结构方向的短像素纹；暖面用木蜜，接缝用栗木影，不画写实木纹。
- **石**：不规则但可归纳的块面；湿面增加一小段雾蓝高光，干面保留湿石褐；石基比墙体更深、更重。
- **屋顶**：层叠短条或菱形瓦片，瓦片方向必须服从屋脊；只在屋檐和破损处使用高对比。
- **金属/青铜**：铜橙小面积高光 + 河岸青冷面 + 深溪墨接缝；避免镜面渐变。
- **织物/旗帜**：麦秆金、雾蓝或苔叶绿的大色块；用 1–2 个折线像素表达褶皱，不能喧宾夺主。
- **水与玻璃**：雾蓝基底、乳白纸短高光、河岸青阴影；用 2–4 个有节奏的块状反射表达流动。

## 5. 角色、建筑、UI 与动画统一规则

### 5.1 角色

角色以 32×48 px 读形为基准：头、躯干、手部工具、鞋和职业色块必须分离；职业身份由工具、姿势和 1 个主色块表达，不依赖脸部细节。角色不可使用现成农场游戏的发型、服装、脸型或配色组合。建筑门口须留出至少 1 个角色宽度的可读入口，并在遮挡时显示脚部/交互标记。

### 5.2 建筑

建筑必须先有独立 silhouette，再有材质。核心识别来自“水工功能 + 中世纪木石结构 + 溪谷环境”三者组合，例如分层水轮、窄高谷仓、带导水檐的工坊；不得用通用方盒加屋顶直接套皮。每栋建筑至少定义：功能锚点、入口、屋顶层级、基础、一个原创识别件和一种状态变化。

### 5.3 UI

UI 使用乳白纸/湿石褐底，深溪墨文字，铜橙或苔叶绿做重点。面板采用纸签、木牌、铜扣的抽象语汇，但不可复刻任何既有作品的布局、图标或字体。状态必须同时有文字/图标/形状或动画表达，不能只用颜色。

### 5.4 动画

动画保持 2–6 帧的低成本节奏：门开合、旗帜轻摆、水流循环、烟雾上升、升级部件闪一下。反馈顺序是“动作发生 → 建筑状态变化 → 短暂强调 → 回到稳定态”；禁止持续闪烁、快速频闪和难以阅读的装饰运动。动画帧必须保持同一 silhouette、基线、调色板和像素密度。

## 6. 建筑设计硬规则

1. 每栋建筑提交三张独立 silhouette：`A 功能优先`、`B 轮廓优先`、`C 叙事/环境优先`，并由内容负责人选择一张进入生产。
2. silhouette 必须在 1×、2× 放大、灰度和纯色缩略图下仍可区分；不能靠纹理或文字才认出功能。
3. 建筑分为 `base`、`structure`、`roof`、`detail`、`interaction`、`state_fx` 六层；层之间不得把可变状态烘焙进不可变底图。
4. 建筑的运行时碰撞、入口、遮挡和交互点必须可追踪到规范模板中的网格与 ID，不由图像猜测。
5. 任何升级至少改变一个轮廓层级或功能锚点，并保留原建筑身份；只换颜色不算升级。
6. 最终资产须通过像素检查、最近邻导入检查、运行时截图检查和原创性检查，缺一不可。

## 7. Prompt 约束短版

后续建筑 prompt 必须包含：`原创溪谷中世纪木石建筑`、`24×24 像素网格`、`暖色但有雾蓝冷平衡`、`深溪墨而非纯黑粗边`、`清晰功能入口与可读 silhouette`、`六层生产结构`、`最近邻整数缩放`、`不近似任何既有游戏或现实地标`。必须从[建筑规范模板](building-art-style-spec-template.md)填充建筑的唯一变量；不得添加外部风格名、外部色板或外部作品名。

## 8. 变更与优先级

冲突时按以下优先级执行：原创性红线 > 可读性/反馈 > 像素规格与导入安全 > 调色板与材质 > 装饰细节。任何修改先更新本 Master Doc，再更新 Skill 与模板；未同步前，不得用于生成新资产。
