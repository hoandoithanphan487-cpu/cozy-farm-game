## 7. 生成 Prompt 合同

将以下模板中的尖括号替换为本表事实；不要加入任何外部作品名或未批准风格词。

```text
生成一栋《溪谷新芽》原创建筑：<建筑名称>，功能是<功能>，位于<所属区域/地形>。
视觉语言必须遵循美术风格 Master Doc：温暖、清晰、低分辨率像素；中世纪溪谷木石工艺；暖色木蜜/麦秆金与雾蓝/河岸青冷平衡；暗部使用深溪墨、湿石褐或栗木影，禁止纯黑粗描边。

规格：24×24 px 网格，母稿<目标母稿尺寸>，俯视与轻微三分之四结合；入口<入口 tile>，玩家站位<玩家站位 tile>，功能锚点<功能锚点>。
先保证 silhouette 读形，再表达<材质>；原创识别件为<原创识别件>。
按六层生产：base、structure、roof、detail、interaction、state_fx；可交互与状态变化必须可独立替换。
运行时要求：最近邻过滤、整数缩放、透明边界干净、轮廓和基线稳定。
不要角色、不要文字、不要现成游戏资产、不要现实地标复刻、不要外部作品风格模仿、不要渐变、不要 3D 渲染、不要抗锯齿。
```

### HD Presentation Prompt 合同

仅当“输出轨道”为 `HD Presentation` 时使用；已批准 silhouette 与功能件必须直接引用现有记录，不提出新方案。

```text
Use case: style-transfer
Asset type: 《溪谷新芽》建筑高清展示层单体插画
Input images: Image 1 为项目内已批准建筑编辑目标，只允许提升绘制密度与展示质感
Primary request: 将<建筑名称>制作成 2048×2048 RGBA 高清绘本式游戏展示插画
Subject: 保持既有 silhouette、比例、屋顶、地基、入口、<功能锚点>与<原创识别件>完全不变
Style/medium: 遵循 Master Doc §1.4/§2.1；清楚线稿、细腻木石/瓦片/青铜/织物材质、柔和左上暖光、暖木与雾蓝/河岸青冷平衡；清晰度对齐 N-009 立绘展示层
Composition/framing: 单栋建筑，轻微俯视三分之四视角，完整居中，四边透明安全边距
Constraints: 只改变绘制精细度与展示媒介；不重新设计；不改变入口、功能件、配色身份或镜头方向；真实透明背景；无文字、Logo、水印、签名或棋盘格
Avoid: 像素化、低分辨率放大、3D 渲染、照片写实、背景场景、人物、第二栋建筑、投影底板、新装饰、新功能件、外部作品或画师风格
```

## 8. 像素、导入与运行时检查

- [ ] 尺寸与 24×24 网格关系正确
- [ ] 仅使用 Master Doc 色票；无纯黑粗边/渐变/软边
- [ ] 1×、2×、灰度、纯色 silhouette 均通过
- [ ] 六层文件齐全、可独立隐藏，层序正确
- [ ] 入口、碰撞、遮挡、交互点与稳定 ID 一致
- [ ] `SKTexture.filteringMode = .nearest` 或等价配置已验证
- [ ] 整数缩放下无模糊，无运行时重采样
- [ ] 失败加载有可读回退，不影响核心路径
- [ ] 运行时远景/近景/交互/升级截图已保存
- [ ] 存档→重启→读档后状态一致
