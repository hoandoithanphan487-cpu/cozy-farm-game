# Studio task: N-004 轻量加工站（IDEA-001 形态①采纳）

**Status:** planned（2026-08-20 合同起草；DEC-022 采纳登记后开工）
**Role contract:** 专项负责人 🎮 gameplay；部门质量负责人 🧱 tech；实现负责人 Cursor；最终独立验收 Hermes / 🛡️ Quality（按 DEC-015 仅保留一次合同门禁 + 一次独立质量门禁）
**依赖:** N-002 `accepted / APPROVED`（加工利润基线已产出）、DEC-019（B 档采纳）、DEC-022（IDEA-001 形态①采纳）、IDEA-001 影响评估、PRD 6.6/6.8、N-001 表现层基线（程序化视觉/合成音频不回归）

## 1. 玩家结果

玩家把「种植→出售」扩展为「种植→加工→售卖」的第三去向：收获作物后，可在农场放置的**加工站**（原创命名，如「木蜜灶台」，最终以 🎭 content 审核为准）将作物加工成更高价值的成品，再把成品投入出售箱结算。加工与直售并存，形成「何时卖原料 vs 何时加工卖成品」的决策；加工消耗体力（每次 2 点，与 N-002 模拟口径一致）、即时完成、失败不扣料。成品定价按 N-002 经济模拟建议区间（加价 +30%~+40%），瞄准中高单价作物，**不破坏 PRD 6.8.1「单一作物在同等劳动条件下不长期领先超约 25%」**，且首日 174 / 余额 894 教学节奏不回归。

## 2. 实现边界

### In scope

1. **加工站放置物（数据驱动）**：新增放置物稳定 ID（如 `brookseed.placeable.cooking_hearth`，命名待 🎭 content 审核），可放置于农场，复用 `PlacementService`（预览/冲突/可达性/失败不扣材料）。视觉用程序化占位（几何色块 + 中文标签，与 N-001 角色视觉同风格），**不引入位图、不触碰 `Assets/`**。
2. **加工配方（数据驱动）**：至少 3 条加工配方，覆盖中高单价作物（建议溪叶菜、琥珀豆、蜜穗瓜，可含铃花莓；**排除雾萝卜**——N-002 实测其加工净亏 -2.3%）。每配方：1 种原料作物 → 1 种加工成品；输入 `RecipeDefinition` 结构（inputs/outputs/nameKey），成品定价落在原料基础售价 × (1.30~1.40) 区间。配方与成品全部入数据文件，不得写死在 UI 或角色代码。
3. **加工服务**：加工逻辑复用/扩展 `CraftingService.craft` 语义——数据驱动、原子性、**失败不扣料**（原料不足、背包满、未放置加工站等均不改变状态）；加工消耗体力 2 点/次，失败不扣体力。**即时完成，零存档 schema 增量**（不新增加工队列/燃料状态，不需要 schema 迁移）。
4. **交互与反馈**：玩家对准已放置的加工站按交互键打开加工面板（可复用制作面板样式，过滤出加工配方）；成功 ✅ + 中文反馈，失败 ❌ + 简短原因；键鼠/手柄可达（PRD FR-010 既有验收不回归）。
5. **经济落账**：加工成品为可售卖物品（`EconomyCatalog` listPrice 可售判定），投入出售箱→日结→到账全链路正确；加工品与原料不复制、不丢失、不重复结算。
6. **自动化测试**：XCTest 覆盖——加工成功账目一致、失败不扣料/不扣体力、放置物失败不扣料、加工成品出售与日结不重复到账、存读往返一致；**既有全部用例 0 回归**（基线计数以验收时权威 xcresult 为准，当前 ≥228）。

### Out of scope（红线，禁止实现）

- ❌ 「猫猫烧烤店」店名、店主 NPC、新地图、日程、支线、对白剧情（IDEA-001 形态②③均不实现；不新增任何 NPC）。
- ❌ 加工队列/燃料/冷却时间等复杂加工状态（即时完成，零存档增量）。
- ❌ 修改 PRD 6.8 经济基线数值（作物种子价/成长/售价、起始资源、174/894 节奏）；加工成品价是**新增**物品，可新定，但必须满足 6.8.1 约束并落在 +30%~+40% 区间。
- ❌ 触碰 `Assets/`（N-003 资产线文件）、`Audio/`（N-001 资产线）、Godot 文件、`docs/game/project-ledger.md`、PRD/TDD。
- ❌ 位图纹理/外部音频资源；非阻断打磨、性能与发行验收。
- ❌ 不复制任何受保护表达（成品名、配方名、加工站名、文案须为《溪谷新芽》原创）。

## 4. 可观察验收条件（10 条）

- **AC-1 加工站放置**：Given 已解锁加工站配方，When 按既有放置流程放置，Then 成功放置在目标格（预览/冲突/可达性规则沿用），失败放置不扣材料；放置物随存读往返保留。
- **AC-2 加工配方数据化**：Given 实现完成，Then 至少 3 条加工配方 + 对应成品物品全部来自数据文件（ContentCatalog/配方定义），UI 与角色代码零硬编码；原料均为中高单价作物（雾萝卜不得出现在加工配方）。
- **AC-3 加工闭环**：Given 背包有溪叶菜×2 且加工站已放置，When 对准加工站交互并选择加工配方，Then 成功加工：原料扣 2、成品 +2、体力 −2（每次），✅ 中文反馈。
- **AC-4 失败原子性**：Given 原料不足/背包满/未放置加工站，When 尝试加工，Then 显示 ❌ + 简短原因，原料、成品、体力、背包全部不变。
- **AC-5 成品定价**：Given 全部加工成品，Then 定价 = 原料基础售价 × (1.30~1.40) 区间，且全部为可售物品（投入出售箱允许）。
- **AC-6 经济平衡**：Given 加工成品定价，Then 复跑 `scripts/economy-sim.py`（或等价确定性脚本）含加工路径，PRD 6.8.1 领先幅度 ≤25% 不破坏；报告引用 N-002 基线（+20%/+40% 均不破坏、雾萝卜加工净亏已排除）。
- **AC-7 出售与日结**：Given 成品投入出售箱并睡眠，When 日结，Then 明细含成品逐项、货币到账一次；重读自动存档/重试日结不二次到账；原料与成品总量守恒（无复制/丢失）。
- **AC-8 存读往返**：Given 完成放置+加工+投入待结算，When 手动保存→完全退出→重启→读取，Then 放置物、背包成品、待结算项、货币与保存时一致。
- **AC-9 回归与可访问**：Given 既有基线，When clean test，Then 既有全部用例 0 回归（权威 xcresult：失败 0、跳过 0）；加工面板键鼠/手柄可完成（FR-010 不回归）。
- **AC-10 原创性与范围**：Given 全部新增内容，Then 加工站名/成品名/配方名/反馈文案均为《溪谷新芽》原创（经 🎭 content 审核 APPROVED），无「猫猫烧烤店」及任何受保护表达；无新增 NPC、无新地图、无加工队列存档字段。
