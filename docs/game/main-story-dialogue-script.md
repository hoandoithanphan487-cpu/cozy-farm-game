# 《溪谷新芽》十段主剧情对白与人物动线制作稿

> 版本：N-026 v3（人物动线返修）
>
> 用途：剧情编排、后续数据化与配音估量的内容基线。
>
> 当前未接入游戏。对白ID是稿件定位符，不是运行时稳定ID。

## 1. 使用规则

- 前八段均按 `benefit → warning_1 → warning_2 → eruption → aftermath → reveal_callback` 播放。
- 同一小节不应一次吐完。默认一次交谈显示1–3句，场景对白由走位、检查和农务动作分隔。
- `[玩家意图]` 是选择按钮的含义，不是玩家必须说出口的固定台词。
- 普通选择改变NPC支援方式、现场分工与终局账簿批注，不决定剧情能否继续。
- `reveal_callback` 只在《溪谷消遣簿》或《已经玩够》中回放，首次经历事件时不可见。
- 黑猫店员、三花店员、布偶猫店员是现有美术身份标签；正式命名和稳定ID另立任务。
- 明线允许停顿、口误、插话和没说完的话。NPC不必每句都替玩家总结意义；能用手上的泥、湿鞋、冷茶或一只歪筐说清的事，不说大道理。
- `{{reputation}}` 表示读取玩家当时的社会声誉，不是固定数值。

## 2. 人物动线制作规则

- `Qxx_BLK_nn` 是演出稿定位符，不是运行时稳定ID。本文只约定语义站位、入退场理由和玩家经过的节点；格点坐标、NPC日程与寻路另立实现任务。
- 获益、两次预警可以发生在不同游戏日。NPC只因巡渠、送货、办事、传话或继续手中工作而入场，说完便去原本的去处，不凭空集合。
- 每段至少让玩家亲自经过一个能观察、检查或操作的节点。选择之后先发生动作和站位变化，再播放分支回应。
- 同一近景最多保留两至三名主要说话者。七人群戏分批入场、分区补位；农场主路、集市中央主轴、建筑门、交互位和地图出口始终留出通路。
- 分支不能只换台词：人物距离、朝向、同行对象或退场方向也要改变。对白结束立即还给玩家控制，停留、回头或暂不出发都不能造成软锁。
- 首次演出跟随玩家视线，只让后台动作看起来像照料与配合；`reveal_callback` 才切到当时被雨幕、货筐或建筑遮住的一侧，让同一动作显出排练和操控。
- 关键线索同时落在对白或可检查道具上，不只依赖颜色、远景小动作或声音。未实现地点只写“未来剧情检查点”，不得据此推定当前地图已有房间、桥梁或可走道路。
