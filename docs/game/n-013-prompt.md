# N-013 建筑高分辨率展示图生成合同

## 共用执行合同

Use case: `stylized-concept`

Asset type: 独立游戏建筑高分辨率透明展示图

Primary request:
- 以对应的项目内已批准配色概念图为造型参考，重制一栋《溪谷新芽》原创建筑。
- 保持既有选中 silhouette、入口、地基、屋顶层级与功能锚点，不新增第二栋建筑或改变建筑用途。

Style/medium:
- 温暖、清晰的中世纪溪谷手工像素建筑插画；高分辨率但保持锐利、规则、离散的像素块面。
- 24×24 px 网格关系可读；远看先读 silhouette，中看读功能，近看读木、石、瓦、青铜与织物。
- 暖面使用木蜜/麦秆金，冷平衡使用雾蓝/河岸青，暗部使用深溪墨/湿石褐/栗木影；铜橙只作功能焦点，乳白纸只作短高光。

Composition/framing:
- 单栋建筑居中，轻微俯视三分之四视角，正面与一侧同时可读。
- 从最高屋脊到最低地基、台阶和所有外伸功能件完整可见；四边保留均衡透明安全边距，任何部件都不得触边或裁切。
- 建筑主体占画布约 76%–86%，同批五图使用一致镜头高度、左上暖光和像素密度。

Output intent:
- 真透明 Alpha，不是棋盘格、白底或伪透明底。
- 最终处理为 2048×2048 RGBA PNG；源图可保持工具原生尺寸。

Constraints:
- 无人物、动物、植物景观、道路、天空、远景、UI、文字、数字、Logo、水印、签名、投影底板或第二栋建筑。
- 不复刻现实地标，不近似任何既有游戏或画师风格。
- 禁止照片纹理、3D 渲染、连续渐变、软阴影、半透明发光、全局纯黑粗边、抗锯齿模糊。
- 附属的水槽/窄水口只保留属于建筑本体的必要形状，不扩展为背景场景。

- 完整性：后缘石台、前缘水阶、中央水口、两根系缆桩和左右端石基全部入画。

## 迭代规则

- 每栋一次只生成/编辑一张；若失败，只针对该栋的裁切、伪透明、造型漂移或风格漂移做单点返工。
- 不以其他四栋的造型覆盖当前建筑，只共享镜头、光向、色票、像素密度与材质语言。
- 生成后必须先目检完整性，再进入 2048 RGBA 处理和自动校验。
