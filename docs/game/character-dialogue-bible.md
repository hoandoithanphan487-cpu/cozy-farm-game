# 《溪谷新芽》角色对白声线圣经

> 版本：N-023 v1  
> 范围：七名现有可交谈 NPC  
> 当前为叙事与内容基线，不代表样稿已经接入游戏。

## 1. 总体写法

每句对白至少完成两件事中的一件：让玩家认出说话的人，或给玩家一个能采取的行动。不要用大段设定说明代替人物说话。

- 普通对白尽量控制在 12–32 个汉字；情绪句可以短到 4–10 个字。
- 农务提醒说清“哪里、什么状态、现在能做什么”，不说“你不来作物就会死”。
- 同一事实必须经过人物自己的注意力过滤：水工看水路，种源看生长，巡护看边界，涧麦婶看人情，石灯看故事，青砚看证据，絮宁看关系。
- 关系升温不是突然变甜，而是角色逐渐把玩家纳入自己的习惯：多说半句、少留一道防备、愿意承认犹豫。
- 冲突后允许道歉、保留分歧或暂时不说话；不把沉默写成永久惩罚。
- 青砚与絮宁的恋爱可以确认、停在暧昧或退回友谊，三种结果都体面。

## 2. 状态标签

后续数据化时，同一角色的对白池建议按以下状态组合，而不是每天完全随机：

| 标签 | 用途 |
|---|---|
| `first_meet` | 初见与职业定位 |
| `daily_clear` / `daily_rain` | 晴天、雨天日常 |
| `crop_attention` | 今日有需要关注的田务 |
| `conflict_open` | 角色卷入未解决矛盾 |
| `trust_low` / `trust_high` | 低信任与高信任 |
| `plot_resolved` | 剧情善后后的常驻回响 |
| `romance_tender` / `romance_confirmed` | 仅青砚、絮宁使用 |
| `mist_ridge_departure` / `mist_ridge_return` | 猫猫公主隐藏任务前后 |

## 3. 水工学徒

### 声线卡

- 核心性格：认真、能干但仍怕出错；遇事先动手检查，再解释原因。
- 句式：短句，多动词；常把大问题拆成“一处一处来”。
- 常用词：渠口、落差、先试一遍、别急、我再量一次。
- 幽默：对自己的谨慎有一点不好意思，不拿别人出丑。
- 避免：老练说教、过度自信、长篇水利术语、把玩家当下属。
- 成长方向：从“凡事自己扛”变成愿意分工，也敢承认没把握。

### 样稿

- `first_meet`：“先别踩那块湿石，我还没量准。绕半步，鞋不会进水。”
- `daily_clear`：“太阳出来得正好。我去看闸，你去看苗，回来对一遍。”
- `daily_rain`：“雨替你浇了地，没替我看渠口。那边我来。”
- `crop_attention`：“北边两畦喝水慢。先松表土，别一口气再浇满。”
- `conflict_open`：“我知道芦丛要护，可田里的水也在涨。给我一点时间，找第三条路。”
- `trust_low`：“数据我会给你。怎么开闸，让我再量一次。”
- `trust_high`：“我一紧张就想把活全揽走。你提醒我分一半，挺好。”
- `plot_resolved`：“新分水板稳住了。田没涝，芦根也没露白——这回我们都没让。”
- `mist_ridge_departure`：“农场的水我盯着。你回来时，渠里还会是今天这个声儿。”
- `mist_ridge_return`：“听见没？水声没变。欢迎回来。”

## 4. 种源管理员

### 声线卡

- 核心性格：温和、细致、珍惜长期积累；相信好结果需要耐心比较。
- 句式：完整、从容，常用植物状态作比喻，但不句句抒情。
- 常用词：这一批、留种、发芽、先记下来、让它长一晚。
- 幽默：把人的急性子与种子的慢性子轻轻对照。
- 避免：神秘先知腔、唯利润论、把种子人格化到幼稚。
- 成长方向：从守住名录与旧经验，变成愿意公开试验、分享失败记录。

### 样稿

- `first_meet`：“先告诉我你的地偏湿还是偏暖。种子不挑人，挑住处。”
- `daily_clear`：“今天适合晒种碟。你若路过，把最饱满的三粒指给我看。”
- `daily_rain`：“雨声会让人心急，种子不会。等土松下来，再决定补不补播。”
- `crop_attention`：“那排琥珀豆叶色浅，不一定是病。先看新叶，别急着拔。”
- `conflict_open`：“高价很诱人，可一纸独家单，会让别人的种子连发芽的地方都没有。”
- `trust_low`：“我可以给建议，但这一批种子的去向，我还要自己核过。”
- `trust_high`：“失败的那盘我也留着。给别人看见，下一次就少走一段弯路。”
- `plot_resolved`：“收购板写明了数量，大家都能来。好种子终于不用先学会抢位置。”
- `mist_ridge_departure`：“我替你留种，不替你催归期。事情办稳了再回来。”
- `mist_ridge_return`：“你错过了两场小雨，没错过播种。位置给你留着。”

## 5. 溪岸巡护员

### 声线卡

- 核心性格：沉稳、边界清楚、重安全与生态；不爱夸张，也不轻易承诺。
- 句式：简洁，先报观察，再给建议；情绪越重，话越少。
- 常用词：水位、痕迹、先绕开、今晚再看、这条线不能越。
- 幽默：极淡，偶尔用天气拆穿人的自信。
- 避免：冷酷执法腔、万能环保口号、没有证据就训人。
- 成长方向：从独自守边界，变成接受社区协作与试验方案。

### 样稿

- `first_meet`：“石缝松，靠里走。等我插好标，你再去水边。”
- `daily_clear`：“水位退了半指。能采，但别把根一并带走。”
- `daily_rain`：“今晚雨急。地里的水能排，芦丛的水别一次放空。”
- `crop_attention`：“叶面有斑，先看背面。没有虫卵，就别把一畦都判成病。”
- `conflict_open`：“我不是拦你救田。我拦的是把所有水都推给下游。”
- `trust_low`：“先按标线走。等你熟悉这段岸，我再把巡查册给你。”
- `trust_high`：“你看见的不只是一块地了。明早那段岸，跟我一起走。”
- `plot_resolved`：“分水方案能用。农田得水，芦丛也留了喘气的地方。”
- `mist_ridge_departure`：“旧水路我标过了。看见三道白石痕，就别往雾深处追。”
- `mist_ridge_return`：“人数齐，路标齐。很好。别的明天再说。”

## 6. 涧麦婶

### 声线卡

- 核心性格：热心、消息快、很会照顾气氛；缺点是容易把转述说得像亲眼所见。
- 句式：连着说，爱带人物和场面；重要处会主动补一句“这我没亲眼见”。
- 常用词：你听我说、刚才、隔壁桌、这句我可得说明、先别往外传。
- 幽默：生活化，自嘲自己耳朵快、脚步慢。
- 避免：恶意造谣者、无脑大喇叭、永不改口。
- 成长方向：从“先说再核”变成“先标来源再传”，但仍保留热闹和人情味。

### 样稿

- `first_meet`：“新农场主吧？别紧张，我只问三件事——吃没吃、路熟不熟、要不要茶。”
- `daily_clear`：“今早集市都说天好。这个我亲眼见了，太阳就在那儿，错不了。”
- `daily_rain`：“雨一大，消息跑得比人快。你先听，别急着信。”
- `crop_attention`：“有人说你的铃花莓起斑了。等等，这句是听来的，咱先去看篮子。”
- `conflict_open`：“话是从我这桌散出去的，我不能装没听见。你带证据，我负责把更正送回每张桌。”
- `trust_low`：“你不想聊也没事。我把茶放这儿，消息先不往你身上拐。”
- `trust_high`：“以后我说‘听来的’，你就敲一下杯沿。咱俩给这句话拴根绳。”
- `plot_resolved`：“更正我送到了七张桌，少一张都不算。腿酸，心里倒轻了。”
- `mist_ridge_departure`：“农场有动静我先记，不添油，也不加醋——最多给你把茶温着。”
- `mist_ridge_return`：“人回来啦！这句我亲眼见的，今天谁也不用再核。”

## 7. 石灯

### 声线卡

- 核心性格：想象力旺盛、爱表演、真心想让大家开心；知道自己会夸张，也愿意被纠正。
- 句式：先抛出夸张画面，再用一句小声修正落地。
- 常用词：我敢说、简直像、要是写进故事、不过说真的、这一段先删掉。
- 幽默：主动拆自己的台，不拿弱者和灾难当笑料。
- 避免：纯粹撒谎、只会胡闹、每句都像舞台独白。
- 成长方向：学会把事实和故事分开，让想象力成为线索，而不是噪声。

### 样稿

- `first_meet`：“我叫石灯，能把一阵风讲成三幕戏。放心，票不要钱。”
- `daily_clear`：“今天天蓝得像把溪水挂上了天。这个比喻不收证据。”
- `daily_rain`：“雨点敲了三百面鼓——好吧，二十来片屋瓦。”
- `crop_attention`：“那篮莓子像中了古老诅咒。停，这段删掉；水斑而已，先找青砚。”
- `conflict_open`：“夸张是我的手艺，不该拿来吓人。这回我自己收场。”
- `trust_low`：“你怕我又说过头？合理。今天我只讲亲眼见的，句号。”
- `trust_high`：“你会笑，也会在该停的时候叫我停。好听众比好故事难找。”
- `plot_resolved`：“新版故事叫《一篮没生病的莓子》。高潮是大家终于肯看篮子。”
- `mist_ridge_departure`：“雾岭有巨兽——据可靠观察，是一块像巨兽的石头。路标在它左边。”
- `mist_ridge_return`：“英雄归来！这次不删。你们确实回来了。”

## 8. 青砚

### 声线卡

- 核心性格：克制、直率、重证据；不是冷淡，而是不愿用含糊话伤人。
- 句式：先区分事实、推测与感受；判断清楚，少用感叹号。
- 常用词：我看见的是、目前只能说明、对得上、先记为待核、这句算数。
- 幽默：干燥、精确，像在严肃记录里留一小道缝。
- 避免：法官腔、情感迟钝、凡事必须量化、恋爱后突然满口诗句。
- 成长方向：承认感受本身也是事实的一部分，并学会在没有完整把握时表达在意。

### 样稿

- `first_meet`：“你可以把听来的告诉我。只是入册时，我会把‘听来’两个字也写上。”
- `daily_clear`：“昨夜无雨，渠痕却新。先查闸口，别急着怪天气。”
- `daily_rain`：“雨会抹掉浅痕。要核实什么，趁现在记。”
- `crop_attention`：“三片叶变黄，不能推出整畦生病。先看根，再下结论。”
- `conflict_open`：“那句批注是我写的，意思不是传闻说的那样。我会亲自说明。”
- `trust_low`：“我不接受替别人作证。你说自己的部分，就够了。”
- `trust_high`：“你改过判断，也认过错。比一次都不出错更可信。”
- `romance_tender`：“今天记了七条水纹。絮宁来时，第八条让我写错了。”
- `romance_confirmed`：“我不能证明以后每一天都顺利。能确认的是，我想和絮宁一起过下一天。”
- `plot_resolved`：“记录已更正，旧页不撕。错误留下，才知道我们怎么走到正确这里。”
- `mist_ridge_departure`：“契约有两种墨，页码也断了。沿着不该出现的那一笔找。”
- `mist_ridge_return`：“一人出发，两人回来。记录完整。”

## 9. 絮宁

### 声线卡

- 核心性格：柔和、敏锐、擅长听出人与人之间没说完的话；早期过度依赖群体意见。
- 句式：常先复述对方，再补自己的看法；语气轻，但不是没有立场。
- 常用词：我听见的是、大家现在、也许先问问、我原来以为、这次我自己决定。
- 幽默：轻轻点破尴尬，给所有人留台阶。
- 避免：随波逐流的空壳、万能和事佬、为了和谐抹平真实分歧。
- 成长方向：从转述共识变成能形成、表达并承担自己的判断。

### 样稿

- `first_meet`：“大家都想知道你会种什么。我更想知道，你希望这里怎么称呼你。”
- `daily_clear`：“今天每个人都说天气好。难得的是，我也这么觉得。”
- `daily_rain`：“雨把人留在屋檐下，话就容易挤在一起。慢一点听。”
- `crop_attention`：“他们都在猜那篮莓子。我想先问你：你亲手碰过叶子吗？”
- `conflict_open`：“我转述得太快，让别人的猜测借了我的声音。这部分是我的责任。”
- `trust_low`：“你不用立刻相信我。先看我下一次怎么传这句话。”
- `trust_high`：“从前我总问大家怎么想。现在我也会问一句：我自己呢？”
- `romance_tender`：“青砚说那只是水纹册的批注。我知道。可我听见的时候，还是高兴了一下。”
- `romance_confirmed`：“这不是大家商量出来的答案。是我自己的——我想和青砚继续往前走。”
- `plot_resolved`：“我们没有变成同一种想法，只是终于肯把不同的话放在一张桌上。”
- `mist_ridge_departure`：“轮班我排好了，谁累了就换人。你不用靠担心我们来证明你在乎。”
- `mist_ridge_return`：“大家准备了很多欢迎的话。我只想先说：你回来就好。”

## 10. 同一事件的七种说法

事件：玩家发现北边两畦作物叶片发黄。七人不能只替换名字说同一句提示。

| 角色 | 台词 |
|---|---|
| 水工学徒 | “北边两畦喝水慢。先松表土，我去查渠尾。” |
| 种源管理员 | “先看新叶，再看根。老叶发黄，不等于整株撑不住。” |
| 溪岸巡护员 | “别急着施东西。叶背、根边、水痕，三处先看完。” |
| 涧麦婶 | “有人说北边两畦病了——这句先别传。咱们把叶子翻过来再说。” |
| 石灯 | “黄叶军团包围了北田！嗯，只有两畦。先听专业的。” |
| 青砚 | “目前只有叶色变化。原因未定，不处理整片。” |
| 絮宁 | “大家都在猜那两畦。你先告诉我，这几天它们哪里不一样。” |

## 11. 后续接入建议

后续若把本稿接入运行时，应另建实现任务，并先确定：

1. 对白选择器读取哪些既有状态，哪些新状态确有必要。
2. 一次交谈展示 1–3 句，避免连续播放完整对白池。
3. 同日重复交谈使用短回应，不重复发放信任或奖励。
4. 农务提醒只读取可观察的作物状态，不凭空制造危机。
5. 恋爱分支、体面分开和隐藏任务回响均需独立内容验证与存档迁移评审。
