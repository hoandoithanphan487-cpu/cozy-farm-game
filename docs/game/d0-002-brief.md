## 1. 玩家结果

玩家可在游戏中打开设置界面（键盘/鼠标/手柄均可达），按设备类别修改输入绑定——冲突绑定被阻止并说明原因，每个必要动作至少保留一个绑定，可一键恢复默认值；所有输入与无障碍设置（UI 缩放 100%/125%/150%、屏幕震动开关、闪烁减弱、分类音量、慢/标准/快/立即四档文字速度）安全写入机器设置文件并在重启后保持；设置文件损坏时回退默认值并保留错误日志；设置状态随存档记录（schema v7），旧存档迁移到合法默认。运行时修改立即生效，不中断游戏状态。

## 2. 实现边界

### In scope

- **输入绑定系统**：键盘/鼠标/手柄绑定可分别修改；同一上下文冲突绑定阻止并说明原因；每个必要动作至少保留一个绑定；恢复默认值；绑定表数据驱动（稳定 ID）。
- **机器设置文件**：所有输入与无障碍设置安全写入机器设置文件（安全替换 + 保留最近有效备份）；重启后保持；读取损坏设置时回退默认值并保留错误日志（遵循 PRD-NFR-003 精神）。
- **无障碍设置**：UI 缩放 100/125/150%；屏幕震动开关；闪烁减弱；音量分类；慢/标准/快/立即四档文字速度；运行时生效。
- **存档集成**：schema v6 → v7，存档携带设置状态（PRD 6.12）；v6 存档迁移到合法默认设置；SaveValidation 覆盖 settings 字段。
- **设置界面与可达性**：HUD/背包/制作/任务外的设置入口，键鼠/手柄均可完成全部设置操作（FR-010）；输入提示跟随最近使用设备。
- **回归**：既有 198/198 XCTest 保持全绿；新增测试覆盖重绑定冲突、默认恢复、重启持久化、损坏回退、迁移与运行时生效。

### Out of scope

- 玩法、经济、社区事件、水渠主线、作物/物品/配方内容与事务语义的任何改动。
- 正式美术/音频资产（设置界面用原创占位表现；音量分类仅接入现有状态行）。
- 性能/加载/内存优化（M4-001）；发行打包（M4-002）。
- 修改 PRD、TDD、项目台账、既有 brief 与既有证据；删除/重写既有稳定内容 ID。

## 4. 最小可观察验收

1. clean Build/Test：**≥198/198 passed、0 failed、0 skipped、0 编译警告**（xcresult 独立查询为准；新增测试使计数可增加）。
2. 设置界面可由键盘、鼠标与手柄到达并完成全部操作（键鼠路径必须截图/转储证明）。
3. 重绑定：修改某动作绑定 → 冲突绑定被阻止且反馈说明原因；每个必要动作至少保留一个绑定（含尝试解绑最后绑定被拒）。
4. 恢复默认值：一键还原全部绑定与设置，与出厂一致。
5. 重启持久化：修改绑定与设置后完全退出并重启，设置一致（机器设置文件 + 存档 settings 字段双载体核验）。
6. 损坏回退：损坏/非法设置文件 → 启动回退默认值、错误日志写入、游戏可正常进行；损坏存档 settings → SaveValidation 拒绝或回退且不破坏最近有效存档。
7. 无障碍生效：UI 缩放 100/125/150%、文字速度四档、震动开关、闪烁减弱、分类音量在运行时生效（截图/转储证明，非仅存储）。
8. 存档集成：schema v7 携带 settings；v6 存档迁移后 settings 为合法默认；存读往返 settings 一致。
9. 既有路径不回归：新游戏→174 溪票→雨天→社区事件→水渠 20 主路径在设置改动后仍可走通（至少测试层）。
10. 未改动玩法/经济/事务语义；未复制任何受保护表达；`git diff --check` exit 0。

## 5. 一条烟雾路径

启动游戏 → 打开设置（键鼠）→ 将「移动-上」改为冲突键 → 确认被阻止并显示说明 → 改为合法键 → 将 UI 缩放设为 125%、文字速度设为「快」→ 恢复默认值 → 重新设置（缩放 125%、文字速度「快」）→ 保存 → 完全退出 → 重启 → 打开设置确认 125%/「快」与绑定保持 → 手动损坏设置文件 → 重启 → 游戏以默认值启动且错误日志存在 → 读取旧 v6 存档 → 自动迁移、settings 为默认、游戏正常 → 新游戏路径（收获 3 株→174 溪票）在设置生效下完成。
