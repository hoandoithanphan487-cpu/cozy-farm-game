## 1. 风格规范(所有资产必须满足)

| 项 | 规范 |
|---|---|
| 艺术类型 | 原创 cozy 像素艺术(温暖、手工感),**非** 3D 渲染/非水彩/非矢量插画 |
| 角色尺寸 | 32×48 像素(PRD 7.1);生成时要求高分辨率画布(512×512)内居中单个角色,便于程序化裁剪缩放 |
| 作物尺寸 | 32×32 像素（与 `PixelAssetStore.swift` 及现有 PNG 一致） |
| 地块尺寸 | 24×24 像素(PRD 7.1) |
| 调色板 | PRD 7.2 词汇:苔绿、雾蓝、湿土褐、木蜜、铜橙;暗部用环境综合色,**禁止全局纯黑粗描边** |
| 视觉词汇 | 湿润石材、层叠木构、雾气植物、青铜水工件 |
| 背景 | 角色/作物要求**纯白或透明背景**(便于裁剪);不要场景插画 |
| 禁止 | ❌ 无任何角色/图标/构图近似现有一线农场游戏(星露谷/牧场物语/波西亚等);❌ 无全局黑边;❌ 非像素风输出 |

## 6. 生成与落盘指引

1. 在 ChatGPT(桌面应用或网页)中按模板生成,每个资产可迭代 1–3 次选最满意一张。
2. 保存 PNG 到 `macos/CreekSprout/CreekSprout/Assets/`,按第 2 节命名。
3. **生成记录**:每件资产在 `Assets/generation-log.md` 记一行——文件名、日期、用的 Prompt 变体、迭代次数、最终选择理由。
4. 完成后通知 Hermes,进入原创性审核(第 7 节)。

## 7. 原创性审核检查单(🛡️ quality + 🎭 content,逐件)

- [ ] 不近似任何现有农场游戏角色/服装/构图(与一线 cozy 农场游戏资产目测对照)
- [ ] 调色板在 PRD 7.2 词汇内,无全局纯黑粗边
- [ ] 角色与 N-001 主题色/发型定义一致(水工学徒=雾蓝工衣/短发 等)
- [ ] 尺寸符合规范(角色 32×48、作物 32×32、地块 24×24,或可无损缩放至该规格)
- [ ] 背景纯白/透明,便于裁剪
- [ ] 生成记录完整(含 Prompt 变体)

审核结论逐件记录于 `Assets/originality-review.md`(通过/返工+理由)。
