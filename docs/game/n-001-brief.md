游戏从「可操作规格说明书」升级为「有味道的可玩品」:7 名角色(3 职能 + 4 邻居)各有可辨识的主题色、发型轮廓与表情,行走/收获/对话有微动效;农场、溪岸、雨天有可听的环境音层;收获/结算/对话/制作有柔和 UI 音效;轻量 BGM loop 可循环不刺耳。全程**零位图纹理**(保持 NFR-007 现状与原创性无忧),音频全部合成生成(不模仿任何受保护旋律)。

## 2. 实现边界

### In scope

1. **程序化角色视觉**:7 角色各定义主题色/发型轮廓/表情状态;移动(行走摆幅)、收获(动作反馈)、对话(表情切换)微动效;「谈/采」角标保留并加状态动画。视觉定义数据化(如 `CharacterVisualDefinition`,稳定 ID 关联现有 `NpcDefinition`),不写死在场景代码。
2. **合成音频**:环境音层——农场(微风/草)、溪岸(流水/鸟鸣)、雨天(雨声),按地图/天气切换;UI 音效——收获/投入/结算/对话/制作/放置;轻量 BGM loop(木质打击+拨弦质感,PRD 8)。音频经 AVAudioEngine/AVAudioPlayer 合成或生成,零外部音频文件依赖。
3. **设置联动**:新音效与 BGM 接入既有分类音量(SettingsState/NFR-010),音量 0 时静音;重启保持。
4. **HUD 兼容**:视觉升级不破坏 HUD 布局与无障碍(形状/图标/文字前缀保留,颜色不作唯一提示)。
5. **测试与证据**:新增测试覆盖视觉定义有效性与音频服务(音量/静音/切换);运行时证据(截图 + 音频触发日志)。

### Out of scope(红线,禁止)

- ❌ 不引入任何位图纹理/音频文件资产(`imageNamed`/`SKTexture(image`/音频文件引用零新增)——NFR-007 现状与 O-3 观察项保持;位图管线属 IDEA-002 第二拍。
- ❌ 不修改内容稳定 ID(`ContentID.swift`/`ContentValidator.swift`)、经济数值(174/894、作物定价)、存档 schema、社区/水渠/任务领域逻辑。
- ❌ 不修改 PRD/TDD/台账;不自我 `APPROVED`;不 `git commit`。
- ❌ 音频不模仿/采样任何受保护旋律、音效或语音(PRD 8 原创边界)。
- ❌ 不重复 clean test(DEC-015;引用 228/0/0 基线 + 运行时烟雾为决定性回归证据)。

## 4. 可观察验收条件(9 条)

- **AC-1 角色辨识度**:7 角色各有主题色/轮廓,静止与移动均可区分(全角色截图对照)。
- **AC-2 微动效**:行走摆幅、收获反馈、对话表情至少各一处可观察(截图序列或录像)。
- **AC-3 环境音层**:农场/溪岸/雨天音层可听且随地图/天气正确切换(音频触发日志 + 采样)。
- **AC-4 UI 音效**:收获/投入/结算/对话/制作至少 4 类触发(日志)。
- **AC-5 BGM**:loop 循环不刺耳;静音/音量分类生效并重启保持(设置文件 diff 全等)。
- **AC-6 零位图**:`imageNamed`/`SKTexture(image`/音频文件引用在源码零命中(NFR-007 保持)。
- **AC-7 回归**:引用 228/0/0 基线;运行时烟雾主路径(新游戏→收获→投入→日结→对话→切图→雨天)不回归。
- **AC-8 红线**:内容 ID/经济/schema/领域逻辑零修改;`git diff --check` exit 0。
- **AC-9 证据包**:截图 + 音频日志 + 新增测试计数,落盘 `artifacts/integration/n-001-*/`。
