# N-003 角色需求清单(供 Product Owner 生成概念图)

**用途:** PO 生成人物概览(概念图),Hermes 负责裁剪/缩放/接入游戏。生成尺寸随意(建议 512×512 或更大),背景纯白或透明,正面站姿、全身。**技术细节(32×48 像素化/透明化/命名)全部由 Hermes 处理,PO 只管画得好看。**

## 通用风格要求(所有角色)

- 原创 cozy 像素/绘本风,温暖手工感;**禁止**近似任何现有农场游戏的角色、服装、构图
- 调色板:苔绿、雾蓝、湿土褐、木蜜、铜橙(PRD 7.2);暗部用环境综合色,**不用纯黑粗描边**
- 视觉词汇:湿润石材、层叠木构、雾气植物、青铜水工件
- 全身正面站姿,表情友善/各自性格,关键道具清晰可见
