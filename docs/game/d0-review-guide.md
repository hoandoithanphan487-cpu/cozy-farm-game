# D0 评审试玩指引（Product Owner 主持）

> 依据：`docs/game/d0-001-brief.md`、`artifacts/integration/d0-001-xcode/issues-feedback.md`、PRD 12/14。目标：PO 实际试玩 VS-1 并给出评审结论（可玩性、问题优先级、M4 输入、D0-002 时机）。**时长以「专注操作 20–35 分钟 + 自由探索」为准（DEC-017），不硬凑 45–60 分钟。**

## 0. 启动方式

```text
open /tmp/creeksprout-d0-001/Build/Products/Debug/CreekSprout.app
```

或 Xcode 打开 `macos/CreekSprout/CreekSprout.xcodeproj`（scheme CreekSprout，My Mac）Run。DEBUG 构建会写 `hud-latest.txt`（HUD 文本转储）。

## 1. 键位（HUD 底部也有）

| 键 | 动作 |
|---|---|
| WASD / 方向键 | 移动（走到石阶进出地图） |
| 1–4 | 切换工具 |
| 空格 / 回车 | 动作/采集；面对石阶也可进出 |

| C / R | 制作 / 切换配方 |
| P / F | 放置预览 / 确认放置 |
| N | 睡眠日结 |
| K / L | 保存 / 读取 |
| Y / B | 切换社区行动 / 提交（首次核实：先「开始核实」再「向青砚核实」；**V 不是入口**） |
| V | 可选恢复：把观察痕迹交给青砚 |

## 2. 主路径脚本（每步预期结果）

1. **新游戏**（农舍醒来）→ 收获 3 株教学雾萝卜（空格收获）。
2. 走到出售箱 **I** 投入雾萝卜×3 → **N** 提前睡眠 → 日结 **174 溪票、余额 894、明细「雾萝卜×3=174」**。
3. 第 1 天白天可选：翻土/播种/浇水 3 格（教学要求）；与水工学徒交谈（T）。
4. **第 2 天**：天气 **雨**，室外已种格自动浇湿（HUD「天气 雨」）；社区事件 **待回应、风评 50、截止第 3 天 23:30**。
5. 到溪岸集市找 **涧麦婶**：Y/B → **「开始核实」** → HUD「核实中、行动记录 1 条」。
6. 走到 **青砚** 旁：Y/B → **「向青砚核实」**（不要按 V）→ HUD「已核实」。
7. 走到 **絮宁** 旁：Y/B → **「纠正絮宁」** → **风评 50→58、水脉 +2、行动记录 3 条**。
8. 保底采集（溪岸/农场 G 点空格采集）→ **C** 制作 **水渠接片**（溪木×6 苔石×4）→ **P/F** 在水道缺口合法放置 → **水脉 +12**。
9. 回水工学徒处 **T 交付** → **水脉 20/20、水道 已恢复、环境音 流水层、新采集点与雨水桶配方解锁**（注意：走纠正分支会显示 22/20，属预期）。
10. **第 3 天**：K 保存 → 完全退出 App → 重启 → L 读取 → 货币/任务/水脉/风评/事件历史全部一致。

## 3. 重点观察项（对应 issues-feedback 问题清单）

| # | 观察点 | 关注 |
|---|---|---|
| 高-2 | HUD 占屏是否挡住石阶/NPC/采集点？窗口拉满是否缓解？ | 试玩可读性 |

## 4. 评审输出（试玩后反馈给我即可）

1. **可玩性结论**：主路径是否顺畅？哪里卡住/困惑？
2. **问题优先级**：上述观察项哪些该在 M4-001 前修、哪些可后置？有无新问题？
3. **时长感受**：专注操作时长是否可接受（DEC-017 口径）？
4. **D0-002 时机**：设置功能是评审后立即做，还是与 M4-001 合并更合理？（当前合同已备妥，随时可启动）
5. **M4 输入**：issues-feedback 的 M4 建议清单（表现/音频/UX/节奏/性能/无障碍/存档）有无增删。

## 5. 评审后流程

PO 反馈 → 🎬 director 将评审结论记入台账（D0 阶段退出门禁「Demo 评审」达成 → D0 关闭）→ 启动 D0-002 与/或 M4-001。
