# N-023 七名 NPC 角色声线与对白样稿

> 状态：`active / PENDING`  
> 专项负责人：📖 narrative  
> 部门质量负责人：🎭 content  
> 跨部门复核：🌱 design

## 1. 玩家结果

玩家不看姓名，也能从句式、关注点和用词判断是谁在说话；同一角色在日常、农务提醒、冲突、关系升温和隐藏任务回响中保持同一种人格，但会产生可感知的成长。

## 2. 依赖预检

- M3-001：`accepted / APPROVED`，七名 NPC、基础对白与稳定 ID 已存在。
- M3-003：`accepted / APPROVED`，社区消息、风评与信任状态已存在。
- N-020：`accepted / APPROVED`，关系剧情和隐藏任务边界已锁定。
- N-021：`accepted / APPROVED`，猫店供货身份与商业边界已锁定。

结论：`PASS`。

## 3. 范围

- 为水工学徒、种源管理员、溪岸巡护员、涧麦婶、石灯、青砚、絮宁建立角色声线卡。
- 提供可直接进入后续对白数据任务的状态化样稿。
- 青砚与絮宁可出现恋爱变化，但不出现求婚、结婚、婚后或玩家强迫配对。
- 本任务不为玩家角色写固定台词，不新增 NPC，不扩写猫店三名展示角色。
- 本任务不修改 Swift、稳定内容 ID、任务状态机、存档 schema、经济或地图。

## 4. 可观察验收

1. 七名角色均有“核心性格、句式、常用词、避用写法、成长方向”。
2. 七人的样稿均覆盖初见、日常/农务、矛盾或低信任、高信任、隐藏任务回响。
3. 同一信息由不同角色表达时，观察角度和句法明显不同。
4. 农务提醒提供行动信息，但不以作物死亡或惩罚威胁玩家。
5. 社交后果源于可见事件，不使用无因减产、永久错过或强制每日登录措辞。
6. 青砚/絮宁恋爱台词保留各自人格，不把恋爱写成唯一正确结局。
7. 文档明确当前是叙事基线，不宣称对白已接入运行时。

## 5. 门禁

- 📖 narrative：角色辨识度、剧情一致性与原创表达。
- 🎭 content：称谓、术语、关系边界与前后状态一致性。
- 🌱 design：提示信息可用、情绪压力温和、无惩罚式留存话术。
