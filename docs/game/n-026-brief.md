# N-026 — 十段主剧情对白与人物动线制作稿

## Player outcome

玩家在5–6小时单次流程中，先把七名NPC当成各有缺点但值得信赖的伙伴，再从相同的口头习惯与旧台词中发现：每一次帮助、赞美和亲近都被他们拿来操纵劳动与风评。终局不把背叛解释成考察、教育或不得已。

## Scope

- 为十段主剧情各写一组可制作的锚点对白。
- 前八段覆盖 `benefit`、`warning_1`、`warning_2`、`eruption`、`aftermath`、`reveal_callback`。
- 第九、十段覆盖发现账簿、集体对质、最后农务与毕业收束。
- 玩家选择只写行动意图，不给玩家固定人格台词，也不设置唯一道德正确答案。
- 猫店三名角色尚无稳定姓名，本稿仅用“黑猫店员／三花店员／布偶猫店员”作为美术身份标签，不视为正式命名。
- 依据 Humanizer-zh 清理模板句、整齐排比、抽象金句、过度解释和总结腔；明线改用具体农活、物件、停顿、插话、口误与局部关心承载信息。
- 暗线与终局也去除“反派主题演讲”感，用八格地、湿鞋、冷茶、备用木牌、缺页和准时货款等旧事翻账，但不削弱全员恶人结论。
- 为 Q01–Q10 增加可排演的人物动线：场景锚点、初始站位、入场理由、玩家移动节点、角色交叉/打断、分支走位、余韵退场与二周目破绽。
- 动线只使用已存在或已确认的语义地点，不写死尚未冻结的格点坐标；不让全员瞬移集合或站成一排轮流念台词。
- 不修改 Swift、地图拓扑、NPC日程/寻路、稳定ID、存档、经济数值、任务状态机、配音或大语言模型接入。

## Acceptance criteria

1. 十段剧情均有独立标题与稳定的稿件对白ID。
2. 前八段完整体现先获益、两次预警、爆发、余韵与终局回扣。
3. 七名NPC不靠替换姓名说同一种话，口头习惯与 N-023 一致。
4. 两次群像事件让玩家在首次游玩时获得明确的英雄感。
5. 第九、十段逐项回收旧铜闸、护田夜、铃花莓、种源、独家单、恋爱矛盾、百桌宴和雾岭营救。
6. 恶意来自两面派、劳动利用与关系背叛，不通过血腥、动物伤害、清档或不可逆经济损失表达。
7. 不涉及结婚，不复制摄影棚、控制室、导演、直播观众或现有影视作品的标志性表达。
8. Humanizer-zh 五维评分达到45/50左右；明线不再出现全员齐声口号或每人轮流给出完整总结。
9. Q01–Q10 每段都有从开场到退场的动线，角色出现有工作或社交理由，关键行动与现有对白顺序相容。
10. 玩家至少经过一个可观察或可操作的空间节点；短演出不长期夺走控制，也不以NPC身体封路。
11. Q02、Q05、Q06、Q07、Q08、Q10 的分支具有对应空间反馈，但不会产生唯一正确路线、失败软锁或额外经济损失。
12. 首次游玩时动线强化熟人共同生活与英雄氛围；揭露时可用相同站位、递物和退场方式回看出预谋，不提前泄底。
