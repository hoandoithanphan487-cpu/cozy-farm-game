# Studio task: M4-001 性能、加载、内存、多槽存档、无障碍补充与 UX 修复

**Status:** planned / PENDING（合同备妥；依赖 D0-002 完成后启动）  
**Role contract:** 专项负责人 🎮 gameplay；部门质量负责人 🧱 tech；合同跨部门复核 🛡️ quality（性能/交付可行性）与 🌱 design（UX/无障碍规则）；下游独立验收 🛡️ quality。  
**合同来源:** 任务登记表 M4-001 行 + PRD 6.12/6.13、NFR-001/002/003、FR-010 + DEC-015 + `docs/game/d0-review.md`（D0 评审结论与问题排期）。

## 1. 玩家结果

游戏在 macOS arm64 参考设备（M4 MacBook Air / 16 GB）的 **Release 构建**上达到性能合同：1920×1080 下 10 分钟压力路线预热后帧时间 P95 ≤16.67 ms、P99 ≤25 ms；连续切图 10 次加载 P95 <3 s；内存无持续增长。存档支持**三个手动槽 + 一个最近自动槽**（睡眠自动保存），写入失败不破坏最近有效存档。D0 评审确认的 UX 与无障碍问题修复：HUD 可折叠/缩小不再遮挡地图、第 3 天目标随状态切换、水脉显示「20 已达成（含纠正 +2 → 22）」、石阶需确认或面对再按、配方选择在切图/读档后保持；无障碍补充（动态字体、减少半透明叠字、色觉以外的状态图标）落地。

## 2. 实现边界

### In scope

- **性能测量与优化**：Release 构建（1920×1080）10 分钟压力路线（含翻种浇/采集/制作/放置/交谈/事件/切图/睡眠循环）帧时间 P95/P99 基线；热点优化（HUD 每分钟整页重排为已知候选热点）；优化后达到 NFR-001。
- **加载测量**：连续切图 10 次（农场↔溪岸集市往返），进入地图加载 P95 <3 s（NFR-002）。
- **内存**：10 分钟压力路线 RSS 基线记录与稳定性验证（无持续增长/泄漏迹象）；PRD 无硬性数字，本任务建立基线并记录，阈值以测量结果 + PO 确认为准。
- **多槽存档（PRD 6.12/388 缺口）**：至少 3 个手动存档槽 + 1 个最近自动存档；睡眠自动保存；暂停/设置菜单允许手动保存（与 D0-002 设置界面协调，不重复实现）；写入失败安全替换 + 备份回退不破坏最近有效存档（NFR-003）。
- **UX 修复（D0 评审排期）**：高-2 HUD 可折叠/缩小（地图至少露出石阶与三名事件 NPC）；高-3 目标行随事件状态切换（纠正后不再复述核实教程）；中-5 水脉显示「20 已达成（含纠正 +2 → 22）」；中-6 石阶离开地图改为确认或「面对石阶按空格」（防收获朝南误传送）；中-7 配方选择在切图/读档后保持（同会话保活或入档）。
- **无障碍补充**：动态字体/文本随 UI 缩放正确适配、减少半透明叠字、色觉以外的状态图标（与 D0-002 的缩放/文字速度/震动/闪烁/音量协调，不重复实现）。
- **回归**：既有全部 XCTest 保持全绿（D0-002 后基线）；主路径（新游戏→174→雨天→事件→水渠 20）回归。

### Out of scope

- 设置功能本体（机器设置文件/重绑定/缩放等）——**D0-002 已承接**，本任务仅做与其衔接的协调与剩余无障碍项。
- 正式像素美术/精灵/角色动画/正式音频/混音。
- 发行打包、安装与离线烟雾（M4-002）。
- 新玩法、新地图/角色/任务/经济数值；PRD 9.2 不含项。
- 修改 PRD、TDD、台账、既有 brief 与既有证据；删除/重写稳定内容 ID。

## 4. 最小可观察验收

1. **Release 构建**成功（0 编译警告/错误）；性能测量基于 Release 产物。
2. **NFR-001**：1920×1080 10 分钟压力路线，预热后帧时间 P95 ≤16.67 ms、P99 ≤25 ms（Instruments/采样日志原始证据）。
3. **NFR-002**：连续切图 10 次加载 P95 <3 s（原始记录）。
4. **内存**：10 分钟压力路线 RSS 稳定（记录起始/峰值/结束，无持续增长）。
5. **多槽存档**：3 个手动槽可创建/覆盖/读取互不干扰；睡眠自动写入最近自动槽；自动槽与手动槽分离。
6. **失败安全**：写入失败（故障注入）不破坏最近有效存档（安全替换 + 备份回退，NFR-003）。
7. **UX 修复**：HUD 折叠后地图可见石阶/NPC（截图）；第 3 天目标不再复述第 2 天核实教程（HUD 转储）；水脉显示「20 已达成（含纠正 +2 → 22）」；石阶离开需确认或面对再按（不再踩上即切图）；配方选择切图/读档后保持（HUD 转储）。
8. **无障碍补充**：动态字体/缩放正确适配、半透明叠字减少、色觉外状态图标（截图/转储；与 D0-002 不重复）。
9. **回归**：既有 XCTest 全绿（计数以最新 xcresult 为准）；主路径（新游戏→174→雨天→事件→水渠 20）在优化后仍可走通。
10. 未改动玩法/经济/事务语义；`git diff --check` exit 0；未复制受保护表达。

Release 构建启动 → 新游戏 → 收获 3 株 → 174 结算（回归）→ 打开 HUD 折叠（地图露出石阶）→ 翻种浇 + 采集 + 制作/放置接片 + 事件核实纠正（含目标行状态切换与 22/20 新显示）→ 睡眠（自动存档写入自动槽）→ 手动存 3 个不同槽 → 切图往返 5 次（记录加载时间）→ 读档（配方保持）→ 故障注入写入失败（最近有效存档不破坏）→ 压力路线 10 分钟（帧时间/内存记录）→ 完全退出重启 → 读档状态一致。
