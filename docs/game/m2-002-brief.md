# Studio task: M2-002 制作 VS-0 场景、教学内容与 10–15 分钟烟雾路径

**Status:** active / PENDING（2026-08-17 开工登记；DEC-015 精简合同）
**Role contract:** 专项负责人 ✨ UX；部门质量负责人 🌱 Design；实现负责人 Cursor / 🎮 Gameplay；最终独立验收 Hermes / 🛡️ Quality（按 DEC-015 仅保留一次部门门禁 + 一次独立质量门禁，🧱 tech 不重复设卡）

## 1. 玩家结果

新玩家**不看任何外部说明、只看游戏 HUD**，即可在 10–15 分钟内走通 VS-0 教学闭环：新游戏后 HUD 始终显示当前教学目标与按键提示；收获 3 株成熟教学雾萝卜 → 投入出售箱 → 翻土 → 播种 → 浇水 → 与农场入口的水工学徒完成一次交谈 → 手动保存 → 完全退出并重启读取（待结算仍为 3、教学进度不倒退）→ 提前睡眠收到一次 174 溪票结算（余额 894）→ HUD 显示 VS-0 范围内的下一目标。每一步完成时教学目标自动推进并显示 ✅ 中文反馈；任何错误操作显示 ❌ 与简短原因且不破坏状态。

## 2. 实现边界

### In scope

1. **教学目标系统（数据驱动）**：新增稳定 ID 教学步骤定义（`brookseed.tutorial.*`），含标题、HUD 提示与完成条件；HUD 只显示当前一步。步骤与完成条件锁定如下（顺序推进，不得跳过）：

   | 步骤 ID | 标题（HUD 文案） | 完成条件（权威状态判定） |
   |---|---|---|
   | `brookseed.tutorial.harvest` | 收获 3 株成熟雾萝卜 | 累计收获 3 株成熟雾萝卜（教程状态记录收获计数） |
   | `brookseed.tutorial.deposit` | 按 I 把雾萝卜投入出售箱 | `economy.shipping` 待结算雾萝卜数量 = 3 |
   | `brookseed.tutorial.till` | 用锄头（1）翻一块地 | 存在任一 `prepared` 地块 |
   | `brookseed.tutorial.plant` | 用种子（2）播种雾萝卜 | 存在任一已播种作物地块 |
   | `brookseed.tutorial.water` | 用水壶（3）浇水 | 存在任一 `wateredToday` 地块 |
   | `brookseed.tutorial.talk` | 与农场入口的水工学徒交谈 | 交谈完成标记置位（随存档往返） |
   | `brookseed.tutorial.save` | 按 K 手动保存 | 成功手动保存后置位（随存档往返） |
   | `brookseed.tutorial.sleep` | 按 N 提前睡眠结算 | 存在第 1 天结算记录且余额 894 |
   | `brookseed.tutorial.next_day` | 下一目标（第 2 天文案） | 睡眠结算后显示；数据驱动文案，不得引入 M3 内容 |

2. **教学 HUD 与反馈**：HUD 常驻「当前目标：…」一行（可含按键提示）；目标推进时显示 ✅ + 中文反馈；无效操作沿用 ❌ + 简短原因，状态不变。反馈必须同时含文字/符号，不只靠颜色（沿用既有 ✅/❌ 前缀惯例）。
3. **水工学徒最小交谈**：新增 NPC 稳定 ID `brookseed.npc.water_apprentice`，VS-0 期间临时出现在农场入口（默认出生点 (6,0)，数据可调），占位图形（人物形状 + 「水工学徒」标签，不进行美术打磨）；玩家目标格为学徒所在格时按交互键触发。对白文本 ID `brookseed.dialogue.water_apprentice.vs0_01`，2–4 句原创教学对白，仅确认当日进度并提示「保存 → 睡眠结算」，按交互键逐句推进、无强制计时；交谈期间通过 `ClockSystem` 的 `PauseReason.dialogue` 暂停游戏时间。交谈完成后学徒保持在场，再次交谈仅显示一行简短回应（幂等：不重复推进教学、不发奖励）。
4. **教程状态持久化**：新增显式 `TutorialState`（当前步骤、已完成步骤集、收获教学株数、交谈/保存完成标记）进 `GameState`；教学进度**不得只存在于临时 HUD 变量**。存档 schema 由 2 提升至 3：`SaveGameDTO` 增加教程状态、`SaveMigrator` 增加 v2→v3（迁移默认置首步 `harvest`，既有 v2 存档可继续游玩）、`SaveValidation` 校验步骤 ID 合法与完成集单调。
5. **既有基线保持不变**：初始货币 720、背包 16 格、雾萝卜种子×8、3 株成熟教学雾萝卜（(4,1)/(5,1)/(6,1)）、出售/日结/农耕规则、174 结算与 894 余额——全部沿用 M2-001 已验收实现，本任务只加引导不重写规则。
6. **自动化测试**：XCTest 覆盖教学步骤推进、错误操作不破坏状态、对白暂停、教程状态存档往返与 v2→v3 迁移；既有 89 项用例（M1/M2）0 回归。

### Out of scope（红线，禁止实现）

- 信任值、日程表、赠礼、社区事件/风评、任务系统、第二张地图（溪岸集市）、水脉复苏/贡献、采集点、商店——全部属 M3，本任务不得实现任何 M3 内容或占位。
- 正式美术/音频、非阻断打磨、性能与发行验收。
- 修改 Godot 文件；修改台账/PRD/TDD；修改 M2-001 已锁定的经济与农耕平衡值。

## 4. 可观察验收条件（10 条）

- **AC-1 初始引导**：Given 新游戏，When 玩家只看 HUD，Then 显示当前教学目标「收获 3 株成熟雾萝卜」及对应按键提示；初始货币 720、背包 16 格、雾萝卜种子×8、3 株成熟教学雾萝卜保持不变。
- **AC-2 收获与投入**：Given 目标为收获，When 收获 3 株成熟雾萝卜并按 I 投入，Then 背包雾萝卜 3→0、待结算 = 3（单价快照 58），每一步有 ✅ 中文反馈且目标自动推进。
- **AC-3 农耕三步**：Given 教学要求翻土→播种→浇水，When 各完成一次，Then 地块依次出现 prepared / 已播种 / wateredToday 状态且目标逐级推进；在未翻土时播种等无效操作显示 ❌ 简短原因且状态不变。
- **AC-4 学徒交谈与暂停**：Given 玩家目标格为农场入口学徒所在格，When 按交互键，Then 触发 2–4 句原创教学对白；交谈期间游戏时间暂停（`PauseReason.dialogue`）；完成后目标推进，再次交谈幂等（不重复推进、不发奖励）。
- **AC-5 存档往返**：Given 已完成交谈并按 K 保存，When 完全退出→重启→读取，Then 待结算仍为 3、教学进度与保存时一致（已完成不倒退、未完成不丢失）、余额仍为 720。
- **AC-6 睡眠结算**：Given 读取后按 N 提前睡眠，When 日结，Then 只结算一次：收到 174 溪票、余额 894、明细「雾萝卜×3 = 174」；再次读取自动存档或重试日结不二次到账。
- **AC-7 结算后目标**：Given 日结完成，When 查看 HUD，Then 显示 VS-0 范围内的下一教学目标（数据驱动文案，不含任何 M3 内容）。
- **AC-8 错误反馈与无障碍**：Given 任意无效操作（未翻土播种、未成熟收获、空背包投入、背包满取回等），When 操作，Then 显示 ❌ + 简短中文原因且状态不变；所有反馈同时含文字或符号，不依赖颜色。
- **AC-9 教学状态持久化原则**：Given 教学实现完成，Then 教学进度可从权威状态（`GameState`/存档）读取与恢复，随存档安全往返（schema v3 + v2→v3 迁移）；不存在仅存在于 HUD 变量的权威进度。
- **AC-10 15 分钟与原创性**：Given 新玩家只看 HUD，When 完成主路径，Then 从新游戏到收到 174 结算 ≤ 15 分钟，无强制等待/不可跳过演出/人为拖延；全部名称、对白、HUD 文案与布局为《溪谷新芽》原创，无受保护表达。

## 5. 一条完整烟雾路径（锁定路径，逐项取证）

| # | 操作 | 预期 HUD / 状态证据 |
|---|---|---|
| 1 | 启动 App，新游戏 | HUD：第 1 天 06:30、余额 720、背包 16 格、种子×8；「当前目标：收获 3 株成熟雾萝卜」 |
| 2 | 走到 (4,1)/(5,1)/(6,1) 收获 3 株 | ✅ 收获反馈×3；背包雾萝卜×3；目标推进为「按 I 投入出售箱」 |
| 3 | 按 I | ✅ 反馈；待结算 3；目标推进为「翻土」 |
| 4 | 选锄头（1）对准野地按空格 | ✅ 翻土成功；地块出现犁沟；目标推进为「播种」 |
| 5 | 选种子（2）对准翻土格按空格 | ✅ 播种成功；目标推进为「浇水」 |
| 6 | 选水壶（3）对准播种格按空格 | ✅ 浇水成功；水滴标记；目标推进为「与水工学徒交谈」 |
| 7 | 走到学徒旁（默认 (6,0)）按交互键，逐句完成对白 | 对白期间时间停止（时钟不前进）；完成后目标推进为「按 K 手动保存」 |
| 8 | 按 K | ✅ 保存成功（slot_0）；目标推进为「按 N 提前睡眠」 |
| 9 | 完全退出 App → 重新启动 → 读取 | 待结算仍为 3；教学进度仍为「提前睡眠」（保存步骤已完成、不倒退）；余额 720 |
| 10 | 按 N 提前睡眠 | ✅ 日结一次：174 溪票、余额 894、明细「雾萝卜×3 = 174」 |
| 11 | 再次读取自动存档 / 重试日结 | 余额仍 894，不二次到账 |
| 12 | 查看 HUD | 显示 VS-0 范围内下一教学目标（数据驱动文案） |

主路径全程 10–15 分钟，任何一步失败不得阻断后续步骤（可重试，状态不被破坏）。

## 6. Cursor 交付格式（DEC-015 单轮精简交接）
