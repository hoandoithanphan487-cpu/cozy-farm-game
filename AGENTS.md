# Cozy Farm Game Studio

For work in this repository, use the project skill at
`skills/cozy-farm-game-studio/SKILL.md`.

- Treat the user as Product Owner.
- Route each task to one specialist owner and one department quality owner.
- Require the relevant department lead to return `APPROVED`, `REVISE`, or `BLOCKED` before work crosses a department boundary.
- Prevent self-approval; use a cross-department reviewer when one agent fills both specialist and lead roles.
- Read the role, workflow, and genre references required by the skill.
- Build an original cozy farming/life-sim/building game; reuse genre conventions, not protected characters, dialogue, maps, art, audio, code, or other expression.
- Prefer a small playable vertical slice and evidence-backed handoffs.
- Do not spawn subagents unless the user or current runtime authorizes delegation. When delegation is unavailable, adopt the roles sequentially.
